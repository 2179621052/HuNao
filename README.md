# HuNao —— 合作烹饪游戏

一款基于 Unity 开发的多人合作烹饪游戏，玩法参考《胡闹厨房》（Overcooked）。玩家需要在有限时间内完成食材处理、菜品制作、订单交付等任务，达到关卡目标金额以完成挑战。

项目包含单人模式和双人合作模式，支持多关卡选择、订单系统、动态奖励、时间限制及关卡进度解锁。

## 项目展示

- **项目类型：** 2D/3D 合作烹饪游戏
- **开发引擎：** Unity 2022.3.18f1c1
- **开发语言：** C#
- **游戏模式：** 单人 / 双人本地合作
- **关卡数量：** 4 关（每种模式各有独立关卡）
- **项目状态：** 持续开发中

## 核心功能

### 1. 游戏模式与关卡系统

- 单人模式与双人本地合作模式。
- 独立的关卡选择界面。
- 四个可选择的游戏关卡。
- 根据通关进度逐步解锁后续关卡。
- 单人和双人模式分别保存关卡解锁进度。

### 2. 食材处理与菜品制作

- 支持食材的拾取、放置和交互。
- 实现切菜、煎制、煮汤等制作流程。
- 支持食材组合与菜品合成。
- 根据菜品配方判断合成结果。
- 支持食物烹饪状态变化，例如煎熟、烧焦等。
- 通过进度条实时反馈切菜和烹饪状态。

### 3. 订单与客人系统

- 支持不同类型的订单。
- 客人桌台随机生成菜品需求。
- 成功交付正确菜品后获得对应金额。
- 订单具有独立倒计时。
- 订单超时后自动刷新。
- 根据订单剩余时间计算动态奖励。
- 错误交付不会产生收入。

### 4. 金额与关卡目标系统

- 使用统一金额管理系统统计关卡收入。
- 不同交付方式支持不同奖励规则。
- 每个关卡可以独立配置目标时间和目标金额。
- 达到目标金额后判定通关。
- 时间耗尽且未达到目标金额时判定失败。

### 5. UI 与游戏流程

完整的游戏流程：

`主菜单 → 模式选择 → 关卡选择 → 开始提示 → 游戏进行 → 通关 / 失败 → 关卡选择`

- 暂停菜单：支持暂停、恢复和返回主菜单。
- 关卡开始提示界面。
- 剩余时间与目标金额 HUD。
- 通关与失败结算界面。
- 关卡解锁状态可视化。

### 6. 音效系统

- 统一 AudioManager 管理音效和背景音乐。
- 支持短音效播放及循环音效管理。
- 根据烹饪状态切换对应循环音效。
- 为不同音效提供独立音量调节。
- 支持背景音乐、切菜、交付、拾取、放置及烹饪等音效。

## 技术实现

项目开发过程中主要涉及：

- **C# 面向对象编程：** 通过继承、封装和组件化实现游戏交互。
- **事件驱动：** 使用事件通知处理交互状态、进度变化及 UI 更新。
- **状态管理：** 管理食材加工、烹饪、订单和关卡状态。
- **ScriptableObject：** 管理食材及相关游戏数据。
- **Unity UI / TextMeshPro：** 实现游戏 HUD、菜单、进度条和结算界面。
- **PlayerPrefs：** 保存单人和双人模式的关卡解锁进度。
- **AudioSource：** 实现短音效、背景音乐及循环音效播放。
- **Prefab：** 复用游戏对象和 UI 资源。

## 开发说明

本项目采用迭代式开发方式，优先保证核心玩法稳定，再逐步完善游戏体验。

开发过程中注重：
- 功能模块之间的职责划分。
- 尽量通过事件驱动减少不必要的轮询。
- 保持单人和双人模式的独立性。
- 通过实际运行测试验证功能。
- 使用 Git 管理代码变更。
