# HuNao｜胡闹厨房风格厨房模拟游戏

## 一、项目简介

HuNao 是一款基于 Unity 开发的 3D 厨房模拟游戏，参考《胡闹厨房》的核心玩法。玩家可以在厨房中移动、与不同功能的桌台交互，完成食材拿取、切菜、烹饪及汉堡制作等操作。

项目支持单人和本地双人游玩，主要用于学习和实践 Unity 游戏开发、C# 面向对象编程、交互系统设计及游戏状态管理。

### 开发环境

- **游戏引擎：** Unity 2022.3.18f1c1
- **编程语言：** C#
- **输入系统：** Unity Input System
- **开发平台：** Windows
- **项目类型：** 3D 模拟经营 / 本地合作游戏

## 二、已实现的主要功能

### 1. 玩家控制与本地双人模式

- 使用 Unity Input System 实现玩家移动与交互输入。
- 支持单人和本地双人游戏模式。
- 两名玩家拥有独立的移动和交互按键，可分别操作厨房中的桌台。
- 实现摄像机跟随玩家，改善游戏过程中的视角体验。

### 2. 桌台交互系统

- 基于面向对象的设计实现不同类型的功能桌台。
- 支持普通桌台、食材生成台、切菜台、烹饪台、垃圾桶及盘子生成台等交互对象。
- 实现食材和物品的拿取、放置、生成及销毁。
- 通过不同桌台的交互逻辑区分各自的功能，便于后续扩展新的桌台类型。

### 3. 食材加工与烹饪系统

- 实现蔬菜切片等食材加工流程，并通过进度条反馈切菜进度。
- 实现肉饼烹饪状态管理，支持未烹饪、烹饪完成及烧焦等状态。
- 根据不同烹饪状态控制食材的后续处理行为。
- 通过事件更新加工进度 UI，实现游戏逻辑与界面反馈的联动。

### 4. 盘子容器与汉堡配方系统

- 使用容器接口管理盘子中的食材。
- 支持向盘子添加不同食材，并限制重复添加相同类型的食材。
- 使用 ScriptableObject 管理食材数据及相关配置。
- 检测指定食材组合，在满足汉堡配方条件后生成对应成品。

### 5. 游戏菜单与视觉反馈

- 实现开始菜单，支持单人游戏、双人游戏及退出游戏。
- 为桌台添加选中高亮效果，增强交互反馈。
- 实现切菜与烹饪进度显示，帮助玩家了解当前操作状态。
